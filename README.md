All files are the property of Another Axiom LLC and are stored solely for the purpose of archiving game updates. No game resources or assets are provided. Gorilla Tag is a publicly available game that anyone can download for free. By making the decompiled code of Gorilla Tag publicly available, we guarantee that the content posted here does not violate Gorilla Tag's terms of service or rules. This is because an official employee of Another Axiom is releasing the packaged assembly of Gorilla Tag. Prior to a DMCA takedown request or a takedown request due to a violation, we will remove any files requested via email.
